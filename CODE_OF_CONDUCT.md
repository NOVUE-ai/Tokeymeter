# Code of Conduct

Be decent. Assume the other person is trying to build something that works.

Specifically: no harassment, no personal attacks, no demeaning comments. Critique
the code, not the person who wrote it. If you're reporting a bug, remember there
is a human on the other end who will read it; if you're responding to one,
remember someone took time to help.

Maintainers may remove comments, commits, issues and pull requests that don't
follow this, and may ban repeat offenders.

Report a problem by emailing the maintainer. Reports are handled privately.
